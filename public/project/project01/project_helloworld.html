PROJECT 01 / GAME LOGIC

Hello Project

從一個小小的想法開始，練習讓遊戲規則、互動與世界逐步成形。
STATUS / IN PROGRESS GODOT / GDSCRIPT

01 / 專案摘要

Hello Project 是一個用來練習遊戲邏輯與互動設計的實驗性作品。

目前正在整理核心玩法、場景流程與角色互動，希望把每一次測試都留下來，慢慢組合成一個可以自由探索的小世界。

02 / 開發方向

01 / GAMEPLAY

建立清楚的互動規則

讓玩家的每一個操作都能得到明確、自然的回應。

02 / WORLD

讓場景承載故事

透過地圖、物件與細節，逐步完成作品的世界觀。

03 / ITERATION

記錄每次測試

從實作與修正中累積經驗，讓想法變成可以玩的作品。
